# Kanbada API

Start PostgreSQL and create local configuration using the [root README](../README.md), then run `dotnet run` from this directory.

- API: `http://127.0.0.1:5180/api`.
- Scalar: `http://127.0.0.1:5180/api/scalar`.
- OpenAPI: `http://127.0.0.1:5180/api/openapi.json`.

See [API contracts](../docs/api.md), [database](../docs/database.md), [authentication](../docs/authentication.md), and [operations](../docs/operations.md). Technical documentation lives in the root `docs/` folder.
