# Kanbada portal

Start the whole application using the [root README](../README.md).

The portal runs with `npm ci` then `npm run dev`; the API must be listening on port 5180. Open `http://localhost:4173`. API mode is the default.

See [frontend architecture](../docs/frontend.md), [contribution checks](../docs/testing.md), and [API/Scalar](../docs/api.md). Technical documentation lives in `docs/` at the repository root.
